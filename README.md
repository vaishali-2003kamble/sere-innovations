## Sere Innovations — Landing Page (HTML/CSS/JS)

Responsive single-page landing site built for the NayaGrowth Frontend Developer Intern assessment (Business Case: **Sere Innovations**).

### What’s included

- **Hero**: brand + value proposition + primary CTA
- **Problem**: external hatchery dependency and impact on farmers
- **Solution**: what the product is and how it helps
- **Features**: ease of use, temperature, humidity, automatic turning, affordability, candling/monitoring mention
- **Benefits**: control, independence, cost efficiency, simpler operations, confidence/income potential
- **Trust/Credibility**: grounded messaging (no fake testimonials/awards)
- **Who it’s for**: primary + secondary audiences
- **CTA/Inquiry**: simple lead form UI (front-end validation; no backend)
- **Footer**: brand + contact placeholders

### Tech stack

- HTML + CSS + Vanilla JavaScript

### Run locally

- Open `index.html` in your browser.

Optional (PowerShell):

```powershell
cd c:\Users\admin\Desktop\growth
Start-Process .\index.html
```

### Deploy

Any static hosting works:

- Netlify: drag-and-drop the folder
- GitHub Pages: deploy the repo
- Vercel: deploy as a static site

### Notes

- The inquiry form is **demo-only** (no backend). Connect it to a form service (Netlify Forms / Formspree) if you want to collect submissions.
